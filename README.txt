REAL BET 3D — paquete preparado para instalación web y empaquetado Android

Archivos:
- index.html: juego
- manifest.webmanifest: datos de instalación
- sw.js: caché para funcionamiento básico sin conexión
- icons/: iconos de la aplicación

IMPORTANTE:
Para que Chrome permita instalarlo como aplicación y un empaquetador pueda generar un APK, primero hay que publicar estos archivos en un sitio HTTPS (por ejemplo GitHub Pages).
Abrir index.html directamente desde Descargas no activa el modo instalable ni el service worker.

El juego utiliza monedas virtuales sin valor real; no incluye depósitos ni retiros.
